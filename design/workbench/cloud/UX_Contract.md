# 雲端基礎版 UX Contract

版本 WB-017-UX-v1；來源 specs/workbench/cloud.md，WB-017 / AC-WB-017。此文件先定義任務與流程，再由 Screen Spec 定義 UI；不改產品權限、資料欄位或 API。

## 使用者、任務與資訊順序

使用者為管理員預建帳號的專案發起人，不需了解工程工具。核心任務是登入、保存想法、自己寫計畫、追加紀錄並回訪。優先顯示目前位置、可做的下一步、保存狀態；其次是計畫與紀錄。固定提示「AI 尚未啟用；目前由你手動整理計畫。GitHub 連結僅供參考，不會讀取或上傳內容」。資料保存至此雲端工作台／Supabase，僅本人帳號可存取；本機版資料不搬移。此權限說明是設計要求，真實 RLS 仍須驗收。

## 首次與回訪流程（UX 先於 UI）

1. 登入：email／password，說明僅預建帳號可登入。沒有註冊、忘記密碼或管理功能。登入成功並驗證使用者後才讀專案。
2. 所有專案：首次空白，不預選測試資料。唯一主要動作「開始新專案」；回訪從具名卡片「開啟專案」。
3. 新專案：名稱＋想法；保存前說明雲端去向。主要動作「建立專案」。成功回到該專案；只有伺服器確認後顯示已保存。
4. 專案：名稱與想法為背景；主要區「手動專案計畫」及「保存計畫」，其次「追加紀錄」和已保存紀錄。計畫可修改，紀錄只能追加。獨立「GitHub 參考連結」及「保存連結」，空值可清除連結。
5. 所有專案／登出：離開前若有草稿，以既有頁內確認對話「尚有未保存內容，離開會捨棄。繼續編輯／捨棄並離開」避免誤操作；這是導航確認，非新增保存 API。登出先清除本頁 session、所有專案資料及草稿，即使遠端 logout 失敗也不可再顯示舊資料。

## 保存、隔離與恢復

每種 mutation 同時間單次送出，pending 禁止重複點擊。成功更新已保存基準並顯示「已保存」；失敗顯示具體下一步並保留當前同帳號、同專案草稿，只能明確手動重試，絕不自動重送。紀錄送出成功才清空輸入；不因讀取失敗抹除尚未送出內容。讀取載入中顯示等待；錯誤不把空白當成已保存資料。

切換專案先清空舊畫面、草稿、結果與確認狀態，再載入新專案；epoch 和 project identity 檢查忽略晚到回應。載入失敗呈「專案暫時無法開啟／返回所有專案或重新載入」，禁用保存。禁止把 A 草稿掛到 B。操作進行中不切換目的專案。session 過期停用讀寫，清除已載入資料與 session，返回登入提示；當前未保存草稿僅保留於當前分頁記憶，標明原帳號／原專案，重新驗證同一帳號及專案才能由使用者明確恢復；換帳號或明確登出即丟棄。不得把草稿寫入共用 storage、日誌或 URL。沒有 token 過期後自動重送。

## 必要狀態與用語

| 狀態 | 呈現與下一步 |
|---|---|
| 缺少部署設定 | 「工作台尚未完成設定，請聯絡管理員」；禁用登入，無 key／堆疊輸出 |
| 登入中／錯誤 | 「正在登入」；失敗「無法登入，請檢查帳號密碼或聯絡管理員」；密碼不回填／不記錄 |
| 未登入／過期 | 「登入已過期，請重新登入；未保存內容尚未送出」；不顯示他人／舊帳號資料 |
| loading／empty | 文字等待；「還沒有專案，開始保存你的第一個想法」／「尚無紀錄」 |
| denied／zero rows | 「無法存取這個專案，請返回所有專案」；不揭露其他帳號名稱或內容 |
| saving／saved／failed | 按鈕「保存中…」與 live status；失敗「尚未保存，內容保留，請重試」 |
| validation | 欄位旁說明原因、聚焦第一個錯誤；不只用顏色 |
| AI／GitHub 未接入 | 清楚文字；無假 AI 按鈕、模型設定、clone、建立 repo／PR、刪除功能 |

## 可用性與限制

375px 單欄、桌面置中最大 1100px；44px 控制、16px 正文、明確 label，Tab 順序按閱讀順序。主內容跳轉連結、可見焦點、aria-live polite 保存訊息、role alert 錯誤；切換聚焦標題，錯誤聚焦摘要，長文字換行。確認使用可鍵盤操作 dialog，焦點返回觸發者；禁用有文字原因。16px 系統中文字型、slate／indigo flat UI，來源線框不接外部服務。未做真實使用者測試、瀏覽器渲染或安全驗收；後續 UX_REVIEWER 與 DESIGN_GATE 必需。
